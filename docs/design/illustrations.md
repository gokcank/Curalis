# Illustrations

## Purpose

This document defines the illustration and visual asset guidelines used throughout Curalis.

Its purpose is to ensure that all visual assets communicate consistently with the project's philosophy and design language.

Illustrations should support understanding rather than decoration.

---

# Philosophy

Illustrations should reduce stress, explain concepts, and create a welcoming experience.

They should never distract from medical information.

Visual assets exist to improve comprehension—not to entertain.

---

# Design Principles

Illustrations should be:

- Simple
- Calm
- Friendly
- Professional
- Timeless

Avoid trends that may quickly become outdated.

---

# Visual Style

Illustrations should follow a single visual language throughout the application.

Preferred characteristics:

- Flat or soft semi-flat
- Minimal detail
- Rounded geometry
- Soft contrast
- Clean composition

Avoid mixing multiple illustration styles.

---

# Color Usage

Illustrations should follow the semantic color system.

Avoid highly saturated palettes.

Colors should support—not dominate—the interface.

Medical information should always remain visually more important than decorative artwork.

---

# Purpose of Illustrations

Illustrations should be used only when they improve the user experience.

Examples include:

- Empty states
- Onboarding
- Educational screens
- Error recovery
- Permission requests

Avoid using illustrations solely to fill empty space.

---

# Empty State Illustrations

Empty state illustrations should feel encouraging.

They should communicate possibility rather than absence.

Avoid imagery suggesting failure or blame.

---

# Onboarding

Illustrations should introduce concepts visually.

Each illustration should support one clear idea.

Avoid explaining multiple concepts within a single illustration.

---

# Medical Imagery

Medical illustrations should remain neutral.

Avoid:

- blood
- injuries
- surgical imagery
- realistic anatomy
- graphic medical content

Prefer symbolic representations of healthcare concepts.

---

# Medication Representation

Medication should be represented using simplified, generic forms.

Avoid replicating real commercial packaging unless necessary.

Brand identity should never become the visual focus.

---

# Character Design

If people appear in illustrations:

- represent diverse users
- avoid stereotypes
- remain culturally neutral
- avoid exaggerated expressions

Characters should support inclusivity.

---

# Emotional Expression

Illustrations should communicate reassurance rather than excitement.

Avoid exaggerated emotional reactions.

Healthcare software should inspire confidence.

---

# Icons vs Illustrations

Icons communicate actions.

Illustrations communicate ideas.

Never use illustrations where icons are more appropriate.

---

# Emoji Usage

Emoji should not be used as part of the primary interface.

They may be considered in optional educational or onboarding content if they improve clarity.

---

# Mascot

Curalis should not rely on a mascot to communicate with users.

Trust should come from clarity, reliability, and consistency.

If a mascot is introduced in the future, it must remain optional and never replace functional guidance.

---

# Background Artwork

Large decorative backgrounds should be avoided.

Whitespace is preferred over decorative graphics.

---

# Animations

Illustrations may include subtle animations where they improve understanding.

Animation should never distract from important information.

Respect reduced-motion preferences.

---

# Asset Quality

Illustrations should:

- scale cleanly
- remain sharp on all supported densities
- support light and dark themes where practical

Prefer vector assets whenever possible.

---

# Accessibility

Illustrations should never contain essential information that is unavailable elsewhere.

Users must be able to complete every task without interpreting illustrations.

Provide meaningful accessibility descriptions where appropriate.

---

# Localization

Illustrations should remain culturally neutral.

Avoid:

- language-specific text
- culturally specific gestures
- region-specific symbolism

Artwork should require little or no localization.

---

# Future Evolution

New illustration styles should remain compatible with the existing visual language.

Visual consistency should be preserved across future releases.
